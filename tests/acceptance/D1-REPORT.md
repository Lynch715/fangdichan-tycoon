# D1 机器人经营工具验收

2026-10-26 · Codex。D1完成；D2目标已经用户确认，尚未达标。

## 策略行为

`src/sim/bots.ts` 是批量模拟中的玩家机器人，具名同行仍由原 `rivals.ts` 驱动。两种策略在月度决策日估算到期本金、土地尾款、利息及工程现金压力；拿地后及时选总包，按当前资金状况选择品牌/标准/低价档。可售项目按周期调整营销。

压力下先考虑未预售项目合作、商票、开发贷和符合条件的展期，再按风险偏好融资，仍有缺口时转让正净回笼项目。激进策略可使用明股实债，保守策略使用比例为0；商票作为到期现金义务计入且不申请展期。保交楼挑战目标不得因机器人自救而被提前转卖。拍地预算考虑已承诺地价、已缴押金、近期待还债务和工程储备，并限制同时经营与已报名数量。

规划使用独立副本逐条调用真实applyCommand，成功后才把指令加入计划；不推进未来、不抽未来随机数、不改变原状态。副本不复制历史报表和同行账本，这些历史不参与所用命令的经济校验，真实指令仍由runGame在原状态再次执行并记完整日志。无待办的月内日期直接返回。

## 参数和历史

只新增 `data/config.json:bots`，其余配置与 `d1-config-before.json` 深度一致，未改变经济内核、真实同行行为、冻结旧档或存档v15格式。旧v15模式档重放派生配置会多出只供机器人使用的bots字段，历史现金、项目与合同规则不变。旧配置比较辅助函数仅排除新增bots字段，旧经济字段仍完整比较。

初值：最低借款/转让净回笼1000万元、现金压力观察3个月、总包选择观察6个月。保守保留初始现金30%、全地价储备、工程储备50%、并行4个；激进保留5%、地价50%、工程15%、并行12个。开发贷使用比例均1；信托0/1，明股实债0/0.5；营销正常3%/4.5%、下行4.5%/6%；常态施工正常/加速，压力下放缓/正常。这些是工具策略初值，尚未完成目标调参。
