# B11 片区购房政策验收

2026-10-26 · Codex。B11完成，B12–B14及C–D待施工。仅本地实现，未初始化Git、未发布。

## 规则与界面

各片区独立维护三个月房价观察值，以真实片区房价和B9全公司库存／销量决定政策。完整观察期之前保持常态；迁移日不补造历史价格或政策。近三个月涨幅≥2.5%，或存在库存、去化≤8个月且房价上涨，视为过热；近三个月跌幅≥1.5%，或存在库存、去化≥30个月／暂无成交且房价涨幅≤0.5%，视为低迷。库存信号需已有三个月真实销量。无库存不当成滞销。

过热升一档、低迷降一档，最低宽松、最高收紧。每次调整后至少观察三个月；平稳时保留现行档位。全公司当月销售完成后统一评估，新政策从下一月销售起生效，不因公司处理顺序产生不同政策。没有新增随机数，也没有改原市场价格生成规则。

|政策|限购|首付|按揭年利率|合资格客群比例|
|---|---|---|---|---|
|宽松|不限购|20%|3.2%|100%|
|常态（初始）|不限购|30%|4.2%|100%|
|收紧|每户限购1套|50%|5.2%|70%|

需求系数＝合资格客群比例×(30%÷首付比例)^0.6×exp[(4.2%−按揭利率)×8]，限制在0.25–1.6。常态精确为1，宽松约1.38，收紧约0.48，乘入原销售率并继续受原销售上限约束。限购通过合资格客群比例模拟，游戏不建立逐户购房数据库；按揭为购房需求参数，不是开发商借款成本。已成交合同、已回款金额不追溯变更。交付后满原定期限的尾货折价清盘规则保留，不走普通销售率。

片区市场展示三项政策、观察期／涨跌幅、调整依据和需求系数；拍卖卡和项目卡显示所在地政策，拍地测算及预计月去化使用同一系数，测算注明政策固定为当前条件。UI只读，所有政策更新经stepDay月末执行。
