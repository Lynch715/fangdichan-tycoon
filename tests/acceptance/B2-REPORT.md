# B2 停工与保交楼验收 · 2026-10-25

已完成。现金不足支付本项目当月工程款的现金部分时，不扣该工程款、不增加工程资产或进度，也不签发未实际支付工程的商票。连续6个月结算未能复工时政府接管，监管账户、剩余货值与交付义务退出公司报表；原开发贷、商票和土地欠款仍留在原公司。补资后在下一次月末真正支付工程款才复工，连续停工计数清零。事故单独停工不启动资金停工计数。

资金不足判断按项目当前施工节奏、当月工程成本、合作权益和商票比例计算。土地款、税费、利息、债务到期及事故损失仍按各自规则支付，可能造成现金为负；本项只改变工程款不足的处理。停工期间已取得预售资格的项目仍可销售回款自救，接管后停止销售、工程、备案和项目操作。
