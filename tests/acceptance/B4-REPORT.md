# B4 品牌与营销投入验收 · 2026-10-25

已完成。公司品牌0–100分，在售项目可单独设置营销投入占实际销售回款的比例；品牌与投入共同影响月度去化，营销费按本公司权益承担。新项目和旧档补齐的默认比例沿用既有`sales.marketingRate=0.03`。不在售、已转让或已接管的项目不能调整；非法、负数、非有限或超上限比例拒绝，不改状态。

## 参数与口径

仅新增以下初值，既有参数与冻结B3配置深度相等：

- `marketing.maxRate=0.12`（可设0–12%）
- `marketing.neutralBrand=50`
- `marketing.brandSensitivity=0.006`
- `marketing.spendSensitivity=4`
- `quality.deliveryBrandGain=2`

原去化公式另乘`max(0,1+(品牌−50)×0.006)`与`max(0,1+(项目营销比例−默认营销比例)×4)`，仍受原最高月去化率限制。品牌50、营销3%时两个系数均为1；品牌0/100时品牌系数0.70/1.30，营销0/12%时营销系数0.88/1.36。工程、成本、价格或随机数不会因调整营销直接改变。

营销费为当月实际回款×本公司权益×项目营销比例，与税费一起支付；无回款则没有营销费。达标交付品牌+2，上限100；低质量维权沿用B3的−10，下限0。两者只在首次交付结算一次，转让或接管不奖励品牌。

B1测算使用当前品牌与默认营销比例，并在估算期固定，明确显示假设；不预测交付后品牌增长。另修复标准工程累计到25%时浮点误差导致预售延后一个月的问题，内核、指令资格和项目面板共用同一判断。
