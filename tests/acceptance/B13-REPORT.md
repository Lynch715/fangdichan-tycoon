## 玩家流程与规则

首次进入或重新开始，在页面内选择生涯/挑战/沙盒及从容/标准/严峻。界面显示实际开局资金和其余三个难度维度；确认前没有开局指令，取消不替换存档。确认创建新公司，先留本机重开前备份，设置写入第0日`startGame`日志。成功经营或推进后不能再改模式/难度，失败操作不会锁定开局。

标准生涯保持旧参数与30年结算。难度系数见B13a记录；三类挑战和沙盒只改本场景派生配置，不修改全局基础配置。每局配置生成一次，操作、月结、测算和报表使用同一份；不重复叠乘。

| 场景 | 初始条件与完成标准 |
| --- | --- |
| 5年内销售额破千亿 | 初始资金×20（标准100亿元），每季12–16宗、面积6–12万㎡，全地图开放；5年内新增权益销售额达到1000亿元。只计实际` saleBooked `流水，融资、资本、收购承接的旧合同不计。 |
| 以橙档开局活过下行期 | 资金×0.2（标准1亿元），3处50%进度项目、库存18亿元；14亿元债券本金、48个月、年息5.5%。三档难度都由财务指标真实得出橙档，监管已生效，周期从下行开始。该轮下行结束时须正常经营、现金非负且净资产为正。 |
| 接手违约公司并保交楼 | 原现金−1亿元、已违约2个月，标准救助资本5亿元到账后现金4亿元。璧山/江津两项目工程40%/65%、已售50%/60%、均停工4个月。原预收款6.282亿元，未释放监管款2.9187亿元，存货7.15575亿元；承接3亿元6个月信托/12%、1亿元3个月商票/0%、2亿元18个月开发贷/5.5%。36个月内由本公司完成两项目交付并恢复正常经营；交付前转让或政府接管即失败。 |

挑战结束自动暂停，财务页显示结局和原因，继续经营不重写已经记录的结局。失败后仍可经营直到公司破产。沙盒不会作为挑战刷分。

保交楼原项目/借款/预售款属于接手时存量，进入期初资产负债；救助资本单列融资流水，不当收入。原项目完整利润、IRR和回正因缺少接手前流水而明确不可核实。新的实际销售和交付从开局日记账。历史停工未记录缺口时不显示“缺口0”。

- 新档v15，仅种子、日期、日志、revision及迁移边界；不保存现金/项目/session/rules状态快照。

- B13a的22冻结文件SHA和五份完整状态哈希保留；迁移比较仅去掉新增session与版本标记，全部v14原字段相同。
- 非第0日开局、重复开局、旧历史插入模式指令、无效选择/边界均拒绝。失败重开/导入保留原状态、配置与存档。
