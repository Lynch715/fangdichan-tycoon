## 统计口径

`src/analysis/balance.ts`只读月报和现金流水，不参与游戏模拟。`npm run balance`保留原净资产/破产率/拿地数，新增收益、破产触发分类、下行最大回撤及D2样本目标检查。收益为期末净资产减初始资本，包含提前破产局。

破产原因采用可复核的现金触发口径：从破产月向前寻找最终连续资金困境的首月，按真实流水顺序找到该月最后一次现金由非负转负的支出。此前已经自救成功的危机不计入；本金、利息/展期费、土地款/保证金、工程、罚款/事故、转让补付、营销/税费及其他分开计数。每个破产局仅计一次，分母为破产局数；没有破产时不输出误导的0%分布。历史缺失、无法对账或无可识别触发时明确归为未知。这是触发支出分布，不是单因素经营因果推断，也不把所有本金兑付都声称为商票兑付。

回撤按月末净资产抽样，只在配置id=downturn对应的“下行”月份评估。基准峰值包含开局及此前全部月份（含繁荣期）的最高净资产；每局取最大金额、最大比例，二者可发生在不同月份。负净资产允许超过100%回撤；非正峰值比例不适用。未经历下行的局排除并列覆盖数，不填成零；包含下行期提前破产的月末。分位数沿用原脚本floor(q×n)，不宣称覆盖月内波动。
